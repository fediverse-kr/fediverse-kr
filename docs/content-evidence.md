# Prototype content evidence — 2026-09-08

The scenes are authored examples, not screenshots of the actual products. Characters, communities, counts, books, and events are fictional. Cross-platform interfaces and message delivery are intentionally simplified; the website states that feature support and server policies vary.

Primary references checked for the activity descriptions:

- BookWyrm: https://joinbookwyrm.com/ — reading tracking, reviews, federation with BookWyrm and services including Mastodon.
- Lemmy: https://join-lemmy.org/docs/introduction.html — federated discussion communities, posts, voting, comments.
- Mobilizon: https://mobilizon.org/about/ and https://docs.mobilizon.org/about/ — federated groups and events. Do not imply every fediverse account can register for every event.
- PeerTube: https://joinpeertube.org/ — independent interconnected video platforms; ActivityPub channel following from compatible platforms.
- Misskey: https://misskey-hub.net/en/ — notes, reactions, federated server software. The text reactions in the demo are simplified examples, not a pixel-accurate reproduction.
- Pixelfed: https://github.com/pixelfed/pixelfed — official repository describes photo sharing across the fediverse. Official product link: https://pixelfed.org/.

No claims about universal privacy, no advertising anywhere, guaranteed account portability, unlimited interoperability, reliability, or real server popularity are made.
