# 소프트웨어 미디어 운영 데이터

소프트웨어별 로고·헤더·출처·저작자·이용 조건·캡션·표시 설정은 운영 데이터다.
애플리케이션 소스나 정적 자산 번들에 프로젝트별 목록을 넣지 않는다.
이 문서에 예전처럼 프로젝트별 적용 목록이나 파일명을 복사해 두지 않는다.

## 변경 원칙

- 관리 화면에서 파일과 공개 출처 정보를 저장한다. 이미지를 교체하기 위해
  애플리케이션을 다시 빌드하거나 배포하지 않는다.
- 출처·캡션·맞춤·배경색만 변경할 때는 파일을 다시 선택하지 않고 저장한다.
- 이미지 원본은 기존 콘텐츠 해시 기반 저장소에 보존하고 카탈로그에서 참조한다.
  파일 경로나 내부 저장소 키를 공개 데이터로 노출하지 않는다.
- 표시 크기·맞춤 방식은 데이터에 따른다. 프로젝트 이름으로 CSS나 Rust를 분기하지 않는다.
- 로고와 헤더는 독립적이다. 없는 이미지에는 공통 대체 화면을 사용하며,
  다른 프로젝트나 포크의 이미지를 빌려 표시하지 않는다.
- 원출처와 이미지의 재사용 조건은 구별한다. 조건을 확인하지 못했으면 그 사실을
  기록하며 소프트웨어 코드의 라이선스를 이미지에 자동 적용하지 않는다.

## 기존 자료 이관

기존 내장 이미지와 수집한 원본은 별도의 운영 이관 묶음으로 보존한다.
이 묶음은 애플리케이션 빌드 입력이나 서버 시작 시 시드가 아니다.
이관은 명시적인 운영 명령으로만 수행하며 파일 해시와 대상의 현재 버전을 검증한다.
변경 이력에는 실제 운영 작업으로 기록하고 다른 회원의 변경으로 위장하지 않는다.

이관 전후에는 해당 이미지의 원본 해시, 카탈로그의 나머지 필드,
공개 이미지 응답과 출처 표시를 비교한다. 기존 자료가 보존됐다는 확인 전에
원본 보관본을 삭제하지 않는다.
