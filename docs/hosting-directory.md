# 관리형 서비스 둘러보기

## 목적

한국어 이용자가 서버의 기술 관리를 맡길 서비스를 찾되, 목록의 위치를 품질·추천 순위로 오해하지 않게 한다.

## 표시 원칙

- 운영 주체가 한국에 기반한 서비스, 해외에 기반한 서비스, 운영 지역 미확인 순으로 구분한다. 서버가 설치되는 데이터센터 지역과 운영 주체의 소재지는 다르다.
- 각 그룹 안의 순서는 한국 시간의 날짜에 따라 한 칸씩 순환한다. 기준 순서는 고정된 주소 식별자의 해시로 정하고, 표시 이름·등록 시각·가격·관리자의 추천 점수는 사용하지 않는다.
- 같은 날 같은 자료에는 같은 순서를 사용한다. 다음 페이지는 첫 페이지의 날짜 기준을 유지한다. 목록이 편집되면 그룹 구성에 따라 순서가 달라질 수 있다.
- 표시 위치는 추천 순위가 아니다. 광고·추천 배지·비교 바구니·점수·별점을 추가하지 않는다.
- 운영 지역과 한국어 지원은 별개다. 한국어 지원이 미확인인 해외 서비스를 미지원으로 단정하지 않는다.
- 태그를 지정하려면 공식 근거 주소가 필요하다. 이용자는 기존 회원 편집·변경 이력에서 분류를 수정할 수 있다.

## 화면

- 목록: 기존 디렉터리의 여백·글꼴·색상을 재사용한다. 서비스별 동일한 텍스트 카드에 지역/한국어 지원 태그, 이름, 짧은 소개, 지원 소프트웨어와 상세 링크를 둔다.
- 정렬 안내: 한국 서비스 우선과 일별 순환 기준을 목록 위에 짧게 표시한다.
- 상세: 소개와 태그 다음에 제공자·고객의 담당 범위를 나누고, 공식 출처·확인 날짜·분류 근거를 제공한다.
- 등록/수정/이력: 지역·한국어 지원·분류 근거가 저장되고 복원된다. 예전 이력에 새 항목이 없으면 미확인으로 읽는다.

## 범위와 검증

- 기존 여섯 항목과 수정 이력, 인증·권한·동시 수정 충돌 계약을 보존한다.
- 새 분류 항목과 정렬의 실제 DB 동작, 페이지 경계 및 날짜 기준 고정, 예전 이력 호환을 검증한다.
- 기존 회원 등록·수정·복원 브라우저 흐름에서 태그 저장과 즉시 반영을 확인한다.
- 배포 전 실제 데스크톱·모바일 화면과 자체 diff 리뷰, 전체 격리 PostgreSQL 회귀, Dioxus 클라이언트/서버 릴리즈 번들 및 컨테이너를 검증한다.
- GitOps 배포 후 실제 이미지·상태·목록·상세·공식 출처·분류를 읽어 확인하고 검증한 소스를 공개 저장소에 동기화한다.
