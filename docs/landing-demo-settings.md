## 아이콘

- 멍멍.개집: Lucide의 가는 선형 아이콘.
- 냥냥.타워: Heroicons Solid의 채워진 아이콘.
- 추억.사진: Ionicons의 윤곽 아이콘.
- 곰국.블로그: Bootstrap Icons.

- 브라우저 외곽과 데모 재생 컨트롤은 공통 Lucide를 유지한다.
- `dioxus-free-icons`의 세 가지 기능만 활성화하고 SVG를 빌드에 포함한다. 실행 중 외부 아이콘 API나 아이콘 폰트를 요청하지 않는다.
- 출처·라이선스: [Heroicons (MIT)](https://github.com/tailwindlabs/heroicons/blob/master/LICENSE), [Ionicons (MIT)](https://github.com/ionic-team/ionicons/blob/main/LICENSE), [Bootstrap Icons (MIT)](https://github.com/twbs/icons/blob/main/LICENSE.md).

## 첫 화면 통계

인트로와 ‘어디서부터 알아볼까요?’ 사이에 독립된 낮은 영역을 둔다.
등록된 한국어 서버 수와 가입 계정 수만 두 칸으로 표시하며, 모바일에서도 두 칸을 유지한다.
‘한국어’는 서버의 물리적 위치나 계정 소유자의 국적이 아닌 이용 언어를 가리킨다.
제목, 카드, 카운트업 애니메이션은 사용하지 않는다.

현재 값은 2026-09-10 [프로덕션 홈페이지](https://fediverse.kr/)에서 확인한 서버 78개, 계정 97,269개의 고정 스냅샷이다.
확인일과 출처 링크를 화면에 표시한다. 고유 인원수가 아니므로 ‘명’이 아닌 ‘가입 계정’으로 표기한다.
DB/API 자동 집계는 아직 연결하지 않았으며, 연결할 때 수치와 기준일을 함께 교체한다.

## 재생

왼쪽 표어는 첫 문구만 무작위로 정한 뒤 약 20초 간격으로 네 문구를 순환한다.
세 줄을 한 묶음으로 700ms 동안 전환하고 같은 그리드 셀에 겹쳐 높이가 변하지 않도록 한다.
오른쪽 데모의 재생·장면 선택과는 별개이며 표어에 재생/일시 정지 조작부는 두지 않는다.
숨겨진 탭과 모션 감소 환경에서는 표어 전환을 멈춘다.

네 구간은 작성 / 원글 수신 / 답글 작성 / 답글 수신이다. 구간 수는 늘리지 않는다.
각 진행 막대는 해당 구간의 시작부터 재생하는 버튼이다. 일시 정지 중에도 선택하면 재개하며, 현재 구간을 다시 눌러 되돌아갈 수 있다.
구간 이동은 기존 시나리오 전환 페이드를 재사용하고, 데모의 임시 작성 상태를 초기화한다. 새 화면이 다 나타난 뒤 시간과 클릭 효과를 재개한다.
키보드로도 선택할 수 있으며 모바일 터치 영역은 높이 44px이다. 모션 감소 환경에서는 자동 재생 대신 선택한 구간의 결과를 정지 화면으로 보여준다.
게시 뒤 2초, 모바일 관점 변경 뒤 수신까지 1초를 둔다.
모바일은 작성자 → 수신자 및 답글 작성자 → 원래 작성자를 따라간다.
관점 변경 때 기존 창은 250ms 동안 옅어지고, 새 창은 150ms 뒤부터 450ms 동안 나타난다.
시나리오 변경은 PC와 모바일 모두 기존 창 묶음을 300ms 페이드아웃한 뒤 교체하고 500ms 페이드인한다.
시나리오 전환이 끝날 때까지 새 장면의 시계는 0에 머문다. 좌우 이동이나 확대·축소는 사용하지 않는다.
사이트를 직접 선택하면 일시 정지하고, 재생하면 현재 단계의 관점으로 돌아간다.
전달 구간에는 양쪽에 표시된 같은 원글 또는 같은 답글을 함께 강조한다.

## 타이핑

`src/typing.rs`의 공통 함수에서 한글 음절을 초성·중성·종성으로 분해하고, 입력 단계마다 완성형으로 다시 조합한다.
예: `ㅇ → 아 → 안`, `ㄱ → 고 → 과`, `ㄱ → 가 → 갑 → 값`. 복합 모음과 겹받침의 중간 조합도 표시한다.
음절 단위 시각 효과이며, 다음 음절의 초성을 이전 음절의 받침으로 잠시 넣는 실제 IME 전체 동작까지 재현하지는 않는다.
한글 외 문자는 grapheme 단위로 처리해 이모지 조합이나 결합 문자를 쪼개지 않는다.
짧은 문장은 기존 타이핑 간격을 유지하고 긴 문장은 제출 버튼 클릭 전까지의 시간 예산 안에서 재생한다.

일반 글·사진 설명·답글과 블로그 본문은 공통 `TypingPreview`를 사용한다. 커서는 입력 끝을 따라가며, 전송 중에는 숨기고 일시 정지·모션 감소 설정을 따른다.
자동 입력은 포커스를 가져가지 않는 읽기 전용 textbox이고, 직접 써보는 모드는 실제 textarea와 브라우저의 기본 IME·커서를 유지한다.
